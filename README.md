# Claude 本地环境排查与清理

一个面向 Codex 等本地 AI 编程工具的中文 Skill。适合停用第三方 API 中转或代理后排查本地配置，也适合账户受限后定位本地连接问题。

它会检查 Claude Code、Claude Desktop 及相关 IDE 入口中的 REA 线索、环境变量、代理、Hook、插件、MCP 和启动脚本。检查结束后会列出配置位置、用途和清理风险，逐文件展示脱敏差异。你确认具体改动后，它才会修改对应的键或行，保留正常登录凭证、对话和其他软件配置。

## 使用方法

在 Codex 中引用 [SKILL.md](./SKILL.md)，然后发送：

> 按这个 Skill 检查我的 Claude 环境。先做只读检查，展示发现和逐文件差异，等我确认后再修改。

清理后的报告会分别记录配置复检、官方域名可达性和认证连接结果。账户申诉与恢复由 Anthropic 官方渠道处理。
